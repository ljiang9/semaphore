# semaphore

把文本编码成**旗语（Flag Semaphore）**的终端 ASCII 示意图：每个字母对应发信人两只手臂的 8 个标准位置（45° 一档），工具把每个字母画成一个小人并横向排列。

```console
$ python -m semaphore "SOS"
  |     |     |
  o-    o     o-
 /      |\    /
```

## 安装与使用

纯标准库，无需安装第三方包（Python 3.10+）：

```console
$ python -m semaphore "HELLO WORLD"
$ echo "SOS" | python -m semaphore
$ python -m semaphore --table   # 打印字母-手臂位置对照表
```

- 输入自动转大写；空格会被渲染成一个空位分隔单词。
- 不支持的字符（数字、标点、中文等）会报错并以 exit 2 退出。

## 位置编号（发信人视角）

| 编号 | 方向 | 编号 | 方向 |
|------|------|------|------|
| 1 | 下 | 5 | 上 |
| 2 | 左下 | 6 | 右上 |
| 3 | 左 | 7 | 右 |
| 4 | 左上 | 8 | 右下 |

编号 1→8 按"面对发信人"的顺时针方向排列；示意图按面对发信人的视角绘制（左右是镜像的，属正常约定）。

## 字母表规律与三个特例

字母基本按 `(1,2)→(1,8), (2,3)→(2,8), …` 的顺序排列，但 **J、V、Y 打破规律**（经公开旗语资料交叉核对）：

- `J = (5,7)`（该位置兼作"字母模式"信号）
- `V = (5,8)`
- `Y = (4,7)`

另外 `(5,6)` 是"数字模式"信号、`(4,8)` 是"取消"信号，本工具只编码 A–Z，不渲染控制信号。

## 已知局限

- 教学/趣味用途：ASCII 小人的手臂是近似方向，不是精确 45°。
- 只支持 A–Z 与空格；不支持数字模式（A–J 复用为 1–0 的那套规则）。
- 示意图在等宽字体下对齐，非等宽终端会错位。
- 旗语本身是公开编码，不提供任何保密性。
